# C View · C 语言与数据结构可视化

用 Python 编写的中文桌面教学程序。自由输入 C 代码，在同一条执行流程中观察变量、运算、条件、循环、一维数组、顺序表、栈和循环队列。

![桌面界面](docs/preview.png)

[查看动画演示](docs/animation.gif)

它实现的是**明确限定的教学 C 子集解释器**，不是完整 C 编译器。内置示例都是可以修改的普通 C 代码；数据结构显示由变量状态驱动，不是预先录好的动画。

## 1. 安装与启动

推荐使用独立安装的 **CPython 3.11 或 3.12**。项目声明的最低版本为 Python 3.10。首次安装依赖需要网络；安装后程序可以离线运行，不需要 GCC 或 Visual Studio。

在解压后的项目文件夹打开 PowerShell，确认能看到 `main.py`：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

这些命令不要求激活虚拟环境，因此不用修改 PowerShell 执行策略。

macOS / Linux：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py
```

也可安装为 Python 包：

```powershell
.\.venv\Scripts\python.exe -m pip install .
.\.venv\Scripts\c-view.exe
```

项目只依赖 PySide6 Essentials（包含 Qt Widgets）与 pycparser，不需要 Qt WebEngine。

**Windows DLL 问题：** 如果出现 `DLL load failed while importing QtCore`，先检查 `python -c "import sys; print(sys.executable)"`。本机验证中 Anaconda 3.13 与 Qt 6.12 出现了 DLL 冲突，而独立 CPython 3.12 可以加载同一版本 Qt。建议用独立 CPython 新建虚拟环境，并避免混用 PyQt/Qt 的 DLL 路径。

## 2. 使用流程

1. 从右上角选择一个示例，或点击“新建”输入自己的 C 代码。
2. 点击“单步”，观察黄色高亮语句、变量表和数组单元；也可以点击“完整演示”自动播放。
3. 点击“暂停”保留状态；随后可继续或单步。点击“停止”保留画面并解锁代码；再次播放从头开始。
4. 在代码中放置光标，点击“定位光标所在语句”。程序执行必要的前置步骤，到目标之前暂停，目标行显示蓝色。点击“单步”执行目标。
5. 同一行有多个语句时，在右侧“指定语句”下拉框选择准确的行列位置，再点击“运行到此处”。循环体中的目标执行后，可再次定位到下一次命中。
6. 点击“结构绑定”，选择数组对应的显示方式并填写相关变量名。同一程序可同时显示多个结构。
7. 保存会生成 `.c` 代码与同名 `.cview.json` 绑定配置；打开代码时会自动读取该配置。

循环条件、循环更新、break 和 continue 都有独立步骤。单条复合表达式展示本次结果与状态变化，尚未实现每一个子运算符的分镜动画。

赋值时，绿色箭头从源变量或数组元素平滑伸向目标，然后淡出。例如 `target = source` 和 `a[j] = a[i]` 都有传递动画。数值常量、未绘制的来源和同一单元的自更新不画传递箭头；运算表达式可显示多个实际来源，数组下标读取不会被误画成数据复制。

使用 `a[i]`、`a[j]` 等直接变量下标时，数组上方自动出现带变量名与当前值的小箭头；变量变化时平滑移动，离开作用域后移除。多个数组及同名局部变量分别识别。越界值显示文字提示，指向未绘制元素时也有提示。当前自动指针支持直接变量及其自增/自减下标；`a[i+1]` 等复合下标表达式仍正确执行赋值和传递，但不额外生成表达式指针。

动画由 Qt 时间驱动连续插值，自动播放等待当前动画完成后再执行下一步。单步也播放完整动画；暂停冻结当前位置，继续恢复，停止结束动画并保留结果。定位跳过中间动画，命中后可单步演示；调整窗口时结束当前动画并适配新布局。动画时长随速度调整，至少 320 毫秒以便看清，因此最快设置下实际步骤间隔可能长于滑块数值。

中间下方同时展示变量和数组：声明后尚未赋值的单元为灰色，只显示名字；赋值后变为绿色，显示 `名字 = 值`。本步读操作使用蓝色边框，写操作使用橙色边框；画面上方显示语句和值的前后变化。数组逐个单元记录赋值状态。

运行、暂停时编辑器锁定；停止或重置后可以修改代码，修改将丢弃旧执行状态。停止保留最后画面；重置清空画面。程序输出保留到重置或下一次运行。自动播放的步骤间隔可调整为 100–2000 毫秒。

## 3. 数据结构约定

| 类型 | 绑定字段 | 约定 |
| --- | --- | --- |
| 普通数组 | 数组名 | 展示物理单元和下标 |
| 顺序表 | 数组名、长度变量 | 有效范围 `[0, length)`，容量由数组声明决定 |
| 栈 | 数组名、top 变量 | `top=-1` 为空栈；top 指向最后一个有效元素 |
| 循环队列 | 数组名、front、rear | front 指向下一个出队位置，rear 指向下一个入队位置；预留一个空位 |

容量为 N 的循环队列最多保存 N−1 个元素，空条件为 `front == rear`，满条件为 `(rear + 1) % N == front`。界面同时显示物理下标与逻辑顺序。

可视化不会替用户修正数据结构算法。溢出或空满判断需要写在 C 代码里；非法数组下标由解释器报错，非法结构绑定由视图提示并回退到原始数组。数组未执行到声明位置时不会凭空显示；结构状态变量尚未定义时会显示等待提示。

示例覆盖：

- `basics.c`：变量、运算、for/while、if、continue、printf，最终 sum=16。
- `list.c`：顺序表插入、删除、查找，最终有效元素为 10、99、20、40。
- `stack.c`：入栈、出栈、再次入栈，最终有效元素为 10、20、99。
- `queue.c`：入队、出队、回绕，最终逻辑顺序为 30、40、50、60。
- `mixed.c`：同一个循环同时操作顺序表、栈和队列，演示组合能力。
- `macros.c`：宏容量、表达式宏、abs、固定种子随机数；逐步观察灰框变绿和 x 从 3 变为 7。
- `animation.c`：标量复制、数组元素复制、i/j 指针移动，最终数组为 2、4、4、2。

## 4. 支持的语言范围

- 语句片段，或 `int main(void)` / `int main()` 完整函数；完整程序还可有简单全局数值声明。
- `int`、`float`、`double`，固定容量一维数组，数组容量支持整数字面量及整数常量算术表达式（包括宏展开后的表达式）。
- 声明、初始化、数组下标、赋值、`+= -= *= /= %=`。
- `+ - * / %`，比较运算，逻辑短路 `&& || !`，前后缀 `++ --`，逗号表达式。
- 代码块作用域、局部变量遮蔽、`if/else`、`for`、`while`、`break`、`continue`、`return`。
- 简化 `printf`：字符串格式、`%d`、`%f`、`%%` 和换行；格式与参数类型必须匹配。
- 中文注释，UTF-8 文件；兼容 `#include <stdio.h>`、`#include <stdlib.h>` 和 `#include <cstdlib>`，也接受双引号形式。这些头文件由解释器内置兼容，不读取系统头文件。
- `abs(int)`、`rand()`、`srand(int)`；stdlib/cstdlib 提供 `RAND_MAX=32767`。每次运行默认种子为 1，相同种子重放相同序列。随机算法为教学实现，不保证与特定平台 C 标准库的序列一致；`srand` 无返回值。`cstdlib` 的兼容不代表支持 C++ 或 `std::` 命名空间。
- `#define N 4`、`#define DOUBLE(x) ((x)*2)` 等对象宏、函数式表达式宏，支持嵌套、参数、反斜杠续行和 `#undef`。按预处理的文本替换规则展开，不自动补运算括号；字符串与注释不展开。语句定位保持原文件行列位置。

暂不支持：指针、struct、typedef、自定义函数/递归、malloc、多维/变长数组、字符串变量、char、unsigned/long、强制类型转换、switch、do-while、位运算、scanf、条件编译、递归宏、变参宏、宏字符串化/拼接、多语句块宏，以及上述范围以外的外部库函数。未支持的语法会报错，不会静默跳过。

**数值与语义限制：**

- int 按有符号 32 位范围检查；整数除法向零截断，余数遵循被除数的符号；除零与溢出报错。
- float 和 double 均使用 Python 宿主浮点近似，**不模拟 C float 的 32 位舍入、所有浮点异常或平台 ABI**，因此不能用它研究浮点精度差异。
- 不模拟真实内存地址。结构中的“空闲位”和“未初始化”是不同概念：有效/空闲通过文字标记，灰/绿填充仅表示是否已有值。未初始化的单元只显示名字，变量表中显示 `?`，读取会报错。有初始化列表的数组剩余元素补零，因此这些元素同样为绿色。
- 输入必须避免 C 的未定义行为，例如在未指定求值顺序的同一表达式中反复修改同一变量。这类复杂表达式不属于受保证的语义范围；请拆为独立语句来演示。
- 顺序表/栈/队列属于用户代码和显示绑定约定，不是自动识别任意 C 实现。

**资源限制：** 每次最多 100000 步；代码最多 64000 字符；数组容量 1–4096，存活数组总元素不超过 16384；同时存活变量不超过 512；输出最多 100000 字符。每个数组最多绘制前 64 个单元，执行器仍处理完整数组，界面提示截断。执行日志保留最近 300 行。

宏限制为 256 个定义、32 层嵌套和 10000 次展开；展开后的文本最多 256000 字符。
