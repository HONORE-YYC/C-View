# 0.3 动态赋值与数组指针实施方案

按本轮明确要求实施，沿用现有桌面程序、语义和播放控制。

## 效果

- 赋值的值来自可见变量或数组元素时，绿色箭头从来源方框平滑伸向目标，短暂停留后淡出。字面量、无可见来源和同一单元自更新不画传递箭头。运算表达式可以有多个来源，但数组下标的读取不算被复制的数据。
- 直接使用变量作下标（例如 a[i]、a[j]）时，自动识别对应数组和变量，显示带名称与当前下标的小箭头。下标变量变化后箭头平滑移动；超出数组范围时在该数组旁显示越界位置，不错误指向有效单元；变量离开作用域时移除。
- 动画使用 Qt 时间驱动插值，逐帧只更新箭头几何/位置/透明度，不重复解析代码或重建所有方框。自动播放等待动画完成，暂停冻结动画，继续恢复，停止结束当前动画并保留结果，重置清除；定位操作跳过中间动画，到目标后单步可完整演示。
- 单步触发完整动画，动画运行时防止连续点击截断；窗口调整与结构绑定变化重建几何并清理旧动画。数组仍仅绘制前 64 个单元。

## 实施计划（writing-plans / executing-plans）

1. 在 tests/test_motion.py 编写来源追踪与下标绑定测试，运行并确认缺少功能的失败。修改 runtime.py、engine.py 记录每次赋值的真实来源及变量身份；新增 motion.py 负责按语法作用域识别下标变量。覆盖常量、a[i]=b[j]、复合赋值、嵌套赋值、同名变量、下标越界与循环更新。
2. 在 tests/test_animation.py 编写 Qt 动画测试，确认失败。新增 animations.py 封装 QGraphics 箭头及 QVariantAnimation。修改 views.py 保存方框几何，创建传递箭头和下标指针，在连续时间点验证中间位置、淡出与终止清理。
3. 修改 window.py 与 GUI 测试：刷新去重、暂停/恢复、单步动画、停止/重置、定位快进、速度联动。用现有 work/run_checks.py 运行相关测试及完整回归。
4. 加入可编辑动画示例，更新 README、版本、验证记录；生成并检查动画关键帧和预览。构建 wheel、独立安装验证，更新源码 ZIP。

测试命令：在工作区运行 `python work/run_checks.py -q --tb=short`（使用已配置的本地测试解释器）。不增加项目第三方依赖。
