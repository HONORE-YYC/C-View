# 0.2 修改方案与实施步骤

按用户本轮要求修改现有程序，不改变统一编辑和执行流程。

1. 头文件兼容 `cstdlib`、`stdlib.h`，实现 `abs(int)`、`rand()`、`srand(int)`，提供 `RAND_MAX=32767`。每次运行独立随机状态，默认种子为 1；相同种子可重放。随机序列是教学实现，不保证与任一平台 C 标准库的具体序列一致。srand 没有可参与运算的返回值。
2. 新增独立预处理器，支持对象宏、普通函数式表达式宏、嵌套展开、续行与 undef；不展开字符串和注释，不增加文件读取或系统预处理器依赖。对不支持的条件编译、变参、字符串化与拼接明确报错。展开位置映射到原始代码，使语句定位和报错仍指向用户输入。
3. 中间下方同时显示标量和数组单元。未初始化：灰色填充、仅变量名；已初始化：绿色填充、`名字 = 值`。数组使用 `a[0]` 形式。读操作蓝色边框、写操作橙色边框，不覆盖赋值状态的填充色。结构有效范围用标记/说明区分，不再用灰色表达结构未使用空间。保留上方变量表。
4. 编辑器为 `()`、`[]`、`{}`、单双引号自动配对；选中文本可包裹，已有闭合字符可跳过，空配对可成对退格。注释、字符串内部及转义场景避免误补全。保留只读和输入法正常路径。
5. 回车继承当前缩进，左花括号后增加 4 空格，在 `{|}` 中生成空代码行并将 `}` 放到下一行；Tab/Shift+Tab 缩进或反缩进选中行，独立输入 `}` 时回退到对应块的缩进。

实施顺序：新增行为测试 → 预处理与库函数 → 编辑辅助 → 状态方框与运算说明 → 全套回归、截图与源码包更新。既有 50 项测试作为回归基线，修改不再支持的旧“define 应报错”测试断言。
