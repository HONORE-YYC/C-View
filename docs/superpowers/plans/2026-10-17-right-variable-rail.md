# 中间画布与右侧变量栏

目标：移除重复的运行状态表格，让演示画布占据中间面板剩余全部高度；变量和函数在画布右侧缩小并单列排列。

采用现有 PySide6 场景的两个裁剪区域，改为左右布局。右栏宽度只随窗口宽度变化，不随变量数量变化。左侧数组和结构、右侧标量和函数各有独立滚动条；保留灰/绿/紫填充、读写边框和箭头颜色。函数展开及返回时保留各视图滚动位置。

1. 在 `tests/test_layout_stability.py` 增加右侧单列、无表格及跨区箭头定位的检查，运行并确认旧布局不满足要求。
2. `window.py` 移除表格创建、清理和刷新；将结构绑定按钮移入面板标题行。
3. `views.py` 为裁剪区域增加横向起点；右侧使用较小的单列卡片，左侧按照可用宽度排布数组，支持窄窗口和滚动。
4. 验证独立滚动、函数视图恢复及既有颜色/动画测试，检查真实 Qt 截图。
5. 更新 README 布局说明和截图，完整测试后提交并同步 GitHub。
