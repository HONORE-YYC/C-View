# iostream 教学输入输出

沿用现有 AST 解释器和输入缓冲，不引入本机 C++ 编译器。识别以 cin/cout 为起点的移位表达式链，普通整数移位仍保持现有支持范围。预处理兼容 iostream、using namespace std; 和 std::cin/std::cout/std::endl，保留源码位置，不替换字符串中的内容。

cin 支持已支持的数值、字符、字符数组、数组元素、结构体成员和指针解引用；连写按从左到右执行。使用现有输入弹窗和缓冲，与 scanf 混用。取消时遵守现有整步回滚与重试。错误输入、只读目标、越界报告教学错误；不模拟完整 iostream 的 failbit/clear/EOF 协议。

cout 输出字符串、字符、数值、表达式及 endl；默认浮点有效数字为 6，布尔输出 0/1。输出立即进入现有输出区域。每条连写语句作为一步。暂不扩展 string 类、文件流、iomanip 或自定义流运算符。
