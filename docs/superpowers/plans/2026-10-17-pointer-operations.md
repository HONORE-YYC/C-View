# 基础指针与红色指向动画

目标：支持单级 int、float、double 指针，演示指针取地址、解引用、重新指向和数组遍历。仅本地实现和验证，不提交或上传 GitHub。

执行语义：地址由对象身份和元素偏移组成，不能仅保存变量名。支持空指针、同数组内移动与比较、指针参数和返回；空、未初始化、越界和生命周期结束的地址报错。结构体、动态分配、多级指针、指针数组不在本次范围。

界面：保留现有变量栏和颜色含义；指针变量显示可读目标，例如 `p = &a[1]`。数组目标显示红色小箭头并平滑移动，标量目标也显示红色指向标记。原循环下标仍为蓝色，普通数据赋值箭头仍为绿色，函数动画保持紫色。NULL、未初始化和失效指针不画有效目标箭头。

实施与验证：
1. 语法和预处理：指针声明、函数签名、&、*、NULL，以及明确的受限形状检查。
2. 运行时：地址值、解引用和指针运算；函数调用、状态恢复及身份生命周期测试。
3. 动画：与蓝色下标共存的红色标记、目标切换、滚动定位、暂停继续与清理。
4. 新增指针示例，说明当前支持范围，执行全套测试并检查真实 Qt 截图。
