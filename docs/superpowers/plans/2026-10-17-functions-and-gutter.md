# 函数演示与行号播放实现计划

目标：用行号播放入口替换光标定位；支持非递归自定义函数的整体调用动画和逐句展开演示。

技术：沿用 Python、pycparser、PySide6。语义执行和绘图分离，保留固定区域、独立滚动和手动代码跳转。

1. 编辑器：行号悬停显示播放图标，点击发送行号，不移动编辑光标。空行、非执行行和正在播放时不触发。同行多语句由窗口选择。
2. 语法：记录函数签名、参数、定义位置和函数体；支持数值/void 返回、数值参数、一维数组参数；检查调用和递归。
3. 执行：标量参数复制，数组参数引用原数组；函数只访问全局与自身作用域。记录实际函数执行轨迹，单步按轨迹恢复各步状态，完整播放只呈现调用结果。预算、异常回滚、停止和重置必须保持有效。
4. 控制：点击行号执行前置步骤后演示目标；函数内目标使用真实调用参数定位。单步进入函数局部视图，返回后恢复调用者视图；播放模式显示摘要。
5. 动画：变量区保留紫色函数名框；摘要用紫色输入框、函数框和箭头，随后作用目标变紫并恢复原色。函数内部变量紫色，常规赋值箭头仍为绿色。
6. 验证：语法/作用域/数组引用/返回/嵌套调用/拒绝递归/预算/回滚，行号交互、视图切换、暂停停止、摘要与普通赋值动画，运行完整测试与真实 Qt 截图。
7. 文档：新增函数示例，更新用户 README 的操作方法与支持范围；维护实现记录与用户说明分开。

用户确认：点击主函数调用语句的行号时自动展开演示；普通单步到调用处时提供展开按钮，继续单步则快速演示。无需手动输入参数。展开过程可以暂停、继续、单步和停止，结束后恢复调用者视图并暂停。
