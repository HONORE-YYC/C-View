# 本地验证记录

日期：2026-10-16。版本：0.3.0。

## 已验证

- Windows 上使用独立 CPython 3.12.14、Qt/PySide6 6.12.0 运行完整测试：**119 passed**。
- 执行器覆盖变量、数组、作用域、整数除法余数、逻辑短路、自增、循环嵌套、break/continue、printf、回滚和步数限制。
- 播放控制覆盖暂停不推进、停止后重新开始、指定语句执行前暂停、循环中重复命中和不可达语句。
- 七个普通 C 示例执行完成，并核对顺序表、栈与循环队列的最终内容，以及宏示例的 x=7、动画示例数组 [2, 4, 4, 2]。
- Qt offscreen 测试覆盖窗口构建、单步、播放、暂停、停止、定位、保存与错误状态。
- 修复并加入回归测试：字符串中的 `main(` 误判，十六进制浮点与超长整数异常，不支持的 main 返回类型，过深表达式错误报告，以及同名数组离开作用域后的刷新异常。
- 新增回归覆盖宏的嵌套、文本替换优先级、字符串保护、续行、undef、原始语句行列映射、token 边界、错误参数与超深空参数；覆盖库函数签名、种子重放、void 值误用和失败语句的随机状态回滚。
- 新增 Qt 交互验证配对字符、选区、撤销、Unicode 光标、只读状态及缩进；修复单行反缩进后光标可能跳到下一行的问题。方框测试验证标量灰转绿、运算后仍为绿色、读写边框与数组结构有效范围相互独立。
- 动画回归覆盖标量/数组来源、常量无箭头、嵌套赋值、逗号表达式只返回最后一项、下标读取不作为复制来源；覆盖循环初始指针、移动、多个指针、作用域与越界提示。
- Qt 动画测试检查箭头中间长度、淡出与清理、指针中间位置、真实事件循环内完成、刷新不重启、tick 等待、暂停/恢复/停止/重置、定位跳过、不可见来源、缩放后的按钮状态。只读代码审查发现的三项问题均先补测试复现、再修复：最后一步暂停无法恢复、重布局后单步禁用、逗号前置项错误来源。
- 构建 0.3.0 wheel，并在独立目标目录安装后验证版本、包导入、七个示例、入口函数、Qt 窗口、单步执行与赋值箭头动画创建/完成。
- 从真实 Qt 窗口生成 `docs/animation.gif`、`docs/preview.png`、`docs/animation-array.png`，检查标量/数组传递和指针关键帧的方向与文字可读性。GIF 为采样预览，不代表屏幕实时帧率。offscreen 环境没有自动加载系统字体，截图脚本显式加载了本机中文与等宽字体；字体文件不打包到源码。

## 验证边界

- 本地测试使用隔离的项目测试依赖；本机 Anaconda 3.13 与 Qt 6.12 存在 DLL 加载冲突，已通过独立 CPython 复核。
- 界面验证使用 Qt offscreen，不代表已经测试所有 Windows 显示缩放、多显示器配置或无障碍工具。
- GitHub Actions 已提供，但尚未推送远程仓库触发；不能据此声称 Linux/macOS 或所有 Python 版本已经通过实测。
- 当前版本实现的是文档列出的教学语义；不覆盖完整 C 标准、未定义行为检测、真实内存布局或 float 的 32 位精度。

复现方式：按 README 新建虚拟环境，安装 `.[dev]`，运行 `python -m pytest -q` 和 `python -m build`。
